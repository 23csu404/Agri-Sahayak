# 🌱 Agri Sahayak – AI-Based Agricultural Assistance System

## 📌 Project Overview

Agri Sahayak is an agricultural assistance project designed to support farmers through technology-based solutions. The project aims to make agricultural information and assistance more accessible through an integrated software system.

## 🎯 Objectives

- Develop a technology-driven agricultural assistance platform.
- Provide an accessible interface for users.
- Organize agricultural assistance features in one system.
- Explore the application of AI and software technologies in agriculture.

## 🛠️ Technology Stack

The project uses technologies and tools across its frontend and backend components.

Refer to the project source code and configuration files for the specific technologies and versions used.

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/23csu404/Agri-Sahayak.git
```

**2. Navigate to the project directory**

```bash
cd Agri-Sahayak
```

**3. Install dependencies**

Install the required dependencies using the configuration files provided in the respective project directories.

**4. Configure environment variables**

Use `.env.example` as a reference to configure the required environment variables. Create a local `.env` file with the necessary values.

**5. Run the application**

Follow the setup instructions in the respective frontend and backend directories to start the application.

## 🔐 Environment Configuration

- `.env.example` provides a reference for environment variables.
- Create your own `.env` file locally.
- Do not upload API keys, passwords, or sensitive credentials to GitHub.
